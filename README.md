# Table Counter

A responsive multiplication-table generator. Enter any whole number from
−999,999 to 999,999 to see its table from 1 to 10.

## Run locally

Open `index.html` in a browser. No build tools or dependencies are required.

## Publish on GitHub

Create a GitHub repository named `table-counter`, then push the contents of this
folder to it. The page can be published from the repository with GitHub Pages.
